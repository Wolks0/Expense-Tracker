# Expense Tracker

A simple and responsive web application built with React.js to help users track and manage daily expenses.

## Features

* Add new expenses
* Delete expenses
* View expense history
* Automatic expense summary
* Real-time total calculation
* Responsive user interface
* Local data persistence

## Tech Stack

* React.js
* JavaScript
* HTML5
* CSS3

## Project Structure

```text
src/
├── components/
│   ├── ExpenseForm.js
│   ├── ExpenseItem.js
│   ├── ExpenseList.js
│   └── ExpenseSummary.js
├── App.js
└── index.js
```

## Getting Started

### Prerequisites

* Node.js
* npm

### Installation

```bash
git clone https://github.com/Wolks0/Expense-Tracker.git
cd Expense-Tracker
npm install
npm start
```

The application will run at:

```text
http://localhost:3000
```

## Overview

Expense Tracker enables users to record and monitor daily spending through a clean and intuitive interface. Users can add expenses, remove entries, and view a summary of their total expenditure, making personal expense management simple and efficient.
